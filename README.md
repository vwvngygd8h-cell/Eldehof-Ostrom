# Eldehof 5.2.2 – Lernender Alltag

Eldehof lernt ausschließlich lokal aus ausdrücklich bestätigten oder ignorierten
Autopilot-Vorschlägen und aus tatsächlichen Aufgabenzeiten.

Nach mindestens drei stabilen Beobachtungen entstehen sichtbare Regeln, zum Beispiel:

- bevorzugte Startzeit eines Geräts
- freie Tagesvorschläge seltener zeigen
- Hinweis, dass die sichere Wochenplan-Automatik wahrscheinlich passt

Jede Regel ist sichtbar, einzeln abschaltbar und vollständig zurücksetzbar.
Gelernte bevorzugte Zeiten wirken nur auf neue Planvorschläge. Explizite manuelle
Tagesvorgaben bleiben vorrangig.

Keine Geräte- oder Wärmepumpensteuerung, keine erfundenen Messwerte, keine
Personenranglisten und keine automatische Entscheidung von Sync-Konflikten.
